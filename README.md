# Restaurante
Proyecto pagina restaurante
Juan David Cruz Angel
Julian David Aguilar Zambrano


Con este proyecto se esperaba utilizar todo lo aprendido en clase de desarrollo web hasta primer corte, pero principalmente
se aprendera a buscar e investigar como hacer las cosas que son desconocidas, pues en un mundo laboral que esta actualizandoze 
diariamente, es una habilidad crucial saber como afrentar este tipo de problemas y no esperar a que una persona solucione los 
problemas.

En el proyecto se usa una combinacion HTML CSS y JavaScript que obliga a ser muy creativos al momento de diseñar e implementar
todas estas herramientas en la pagina
